# Visual Generation Rules

Use these rules for BacaYuk storybook visual generation and illustration prompts.

## Scene Prompt Shape

For each page, write:

```text
Subject + action + setting + mood + important object + child-safe style
```

Example:

```text
Raka, a curious Indonesian boy, kneels beside a glowing hand-drawn map in a pine forest village, friendly animals watching, warm afternoon light, colorful children's storybook illustration.
```

## Illustration Types

Map scenes to the closest built-in type first:

- `forest`: village, trees, animals, hiking, maps, nature
- `sea`: river, lake, rain, beach, boats, fish
- `space`: stars, moon, planets, sky journey
- `dragon`: magic, glowing objects, crystals, fantasy creatures
- `castle`: kingdom, palace, towers, royalty
- `garden`: flowers, insects, parks, gentle outdoor scenes
- `custom`: only when none of the above fits or when using image generation

## Page Visual Rules

- One clear focal action per page.
- Keep characters visually consistent across pages.
- Avoid scary, violent, or overly dark imagery for young readers.
- Do not include readable text inside generated images unless the user asks; render text in the app.
- Prefer bright but not oversaturated palettes.
- Use culturally appropriate names, settings, clothing, and objects when the story is Indonesian.

## Cover Rules

Cover prompt should show:

- main character
- main setting
- magical/problem object
- emotional promise of the story

Do not make the cover a collage of every page.

## Review Checklist

- Does each page have a distinct visual beat?
- Can a child understand the scene without reading?
- Are recurring characters recognizable?
- Does the visual match the page text?
- Are image prompts free of markdown/meta instructions?
